# Downloading actas in PDF format

PDF content related to actas will be stored in the `/resources/actas/<season>/<league>/<group>/<sex>/acta_<id>.pdf` folder. 
The script `descargador_actas_2025-2026.py` is used to download the PDF content from the RFETM website for the season 2025-2026 exclusively.

```commandline
  python descargador_actas_2025-2026.py --force
```
