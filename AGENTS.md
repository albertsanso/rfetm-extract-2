# AGENTS.md

RFETM (Real Federación Española de Tenis de Mesa) match-report ("actas") dataset. Web pages and PDFs are downloaded from rfetm sites and parsed into one JSON file per match under `resources/actas-json/`. All code/comments/prompts are in Spanish (Catalonian slugs like `divisio-honor`); keep that language in new work.

## Layout and pipeline

Two self-contained pipelines of standalone scripts (no package, no entry points):

- `src/actas-html/` — HTML result pages, seasons 2019-2020 .. 2024-2025.
  - `web_downloader_rfetm.py` — downloads result pages.
  - `convert-html-actas-to-json.py` — parses downloaded HTML into match JSON.
- `src/actas-pdf/` — PDF actas, season 2025-2026 ONLY (hard-coded).
  - `descargador_actas_2025-2026.py` — downloads PDFs (`clubs.rfetm.es/ligas/partido/<id>/imprimir/acta`).
  - `parser-acta-pdf-2025-2026.py` — parses one PDF.
  - `convert-actas-to-json-2025-2026.py` — batch PDF → JSON, writes `conversion_errors.log`.

Directories: download output lives in `resources/web-downloader/<season>/<cat>/<jornada>/<sex>/grupo_<N>.html` (HTML) and `resources/actas/<season>/<cat>/<grupo>/<sex>/acta_<id>.pdf` (PDF). Converted output mirrors that in `resources/actas-json/`, one file per match `acta_<matchid>.json`. The whole `resources/actas-json/**` tree (35k+ files) is committed to git — do not regenerate en masse without reason.

## Running scripts (no pip install; deps in `.venv`)

```
python src/actas-html/web_downloader_rfetm.py --season 2024-2025 [--force] [--all-seasons]
python src/actas-html/convert-html-actas-to-json.py [--season 2024-2025] [--category divisio-honor] [--force]
python src/actas-pdf/descargador_actas_2025-2026.py [--force]
python src/actas-pdf/convert-actas-to-json-2025-2026.py
python src/actas-pdf/parser-acta-pdf-2025-2026.py resources/actas/2025-2026/<cat>/<grupo>/<sexo>/acta_<id>.pdf
```

- Downloaders are idempotent: skip existing files unless `--force` (which re-downloads).
- No tests, no lint/typecheck config. Verify changes by parsing one file and diffing the JSON against neighbors. JSON output is utf-8, `ensure_ascii=False`.

## Gotchas (easy to trip on)

- **Path bug**: `web_downloader_rfetm.py` and the whole `src/actas-pdf` suite compute `WORKSPACE_ROOT = Path(__file__).parent.parent`, which resolves to `src/` instead of the repo root. They read/write `src/resources/…`, which does not exist here — committed data lives at the repo-root `resources/`. Only `convert-html-actas-to-json.py` uses `.parent.parent.parent` (correct, repo root). If a run reports files missing, this is likely why.
- **RFETM HTTP quirks**: the results server returns HTTP 500 with valid, parseable HTML; `get_page()` treats `200` and `500` with a body as success (500 is intentionally excluded from retries — the server uses it for "no data"). Respect rate limits: built-in ~2s delays, browser-ish User-Agent; the prompts warn the site blocks aggressive automation. Don't spin up fast loops.
- **Encoding**: RFETM pages can be Latin-1; the HTML converter tries utf-8, then falls back to `iso-8859-1`. Don't assume utf-8.
- **Liga codes ≠ folder names**. `liga=MQ==`, `Mg==`, `Mw==`, `NA==` (etc.) become readable category slugs. The two downloaders map them DIFFERENTLY — `descar` uses `Mw→primera-nacional`, `NA→segona-nacional`, while `web_downloader_rfetm.py` maps those to `primera-divisio`/`segona-divisio`. Each matches the folders it actually populated (+`Fasc` variants). Do not "align" the maps without touching the existing folder structure. Unknown codes: `descargador_actas_2025-2026.py` hard-fails (ValueError); the web downloader falls back to `liga-<code>`.
- **PDF converter loads its parser via `importlib`** (`parser_path` points at the file) because `parser-acta-pdf-2025-2026.py` has hyphens and can't be a normal import. Keep that mechanism if you split/rename parser functions.
- **JSON schema**: `resources/actas-json/model-definition.json` is the authority for output shape. Both pipelines emit: `abc_es_local` (decides whether letter rows `local` matches A/B/C or X/Y/Z); `alineaciones`/`partidos` keyed by letters; `marcador_acumulado`, `no_disputado` + `motivo`; doubles are `tipo:"dobles"` with `letra:"Db"` and `jugadores`. Generated by `.codex/prompts/gen-json-model-def.md`.
